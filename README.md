**Course:** Web Technologies (Front-End Development)

## Description

A multi-page, game-themed website called **GameHub** that demonstrates HTML forms, Bootstrap 5.3 form components and form validation (HTML5 built-in and Bootstrap validation classes). Every page has the same navbar that links to all tasks.

## Pages

| Page | Task | What it shows |
|------|------|---------------|
| `index.html` | Home | Overview and links to all tasks |
| `task0.html` | Task 0 | Simple contact form (name, email, message) with labels |
| `task1.html` | Task 1 | Same form with HTML5 validation: `required`, `type`, `minlength`, `maxlength`, `pattern` |
| `task2.html` | Task 2 | Contact form with Bootstrap classes, grid, placeholders, helper text |
| `task3.html` | Task 3 | Bootstrap `is-valid` / `is-invalid` classes with feedback messages |
| `task4.html` | Task 4 | Responsive registration form: names, email, password + confirm, gender, hobbies, country, Submit and Reset |

## Project structure
