Task 1. Form with HTML5 validation

Same form, now with built-in validation attributes. The browser blocks the submit and shows its own message.

How to test

  • Press Send message with empty fields: required stops the submit.
  • Type abc in Email: type="email" rejects the format.
  • Type one letter in Name or fewer than 10 characters in Message: minlength blocks it.
  • Type digits in Name: pattern rejects them. maxlength stops typing at the limit.
